# Conception - <produit> / <écran>

Fiche de conception : elle dit **quoi** construire. Dans la chaîne du
studio, c'est l'agent UX qui la produit dans `design/<ecran>/`. Sans agent
UX (dans claude.ai par exemple), le brief de la demande en tient lieu, ou
ce gabarit rempli à la main.

## Contexte
- Produit : <ce que c'est, pour qui>
- Utilisateur principal : <rôle, fréquence d'usage, contexte : bureau, terrain, mobile>
- Type : écran applicatif | tableau de bord | page vitrine | composant
- Charte : `design/DESIGN.md` (sinon le socle du studio)

## L'écran
- Objectif en une phrase : <ce que l'utilisateur vient faire ici>
- Contenu, par ordre d'importance :
  1. <zone, information ou action>
  2. …
- Action primaire : <une seule>
- Actions secondaires : <liste>
- États à proposer en fin d'écran : <vide, chargement, erreur, succès, et ceux propres à l'écran>

## Données réelles
<Noms, chiffres, dates, textes vraisemblables à utiliser.>
